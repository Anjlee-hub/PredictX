
# PredictX Contribution Rules

## Branches

- main: Stable releases only.
- develop: Integration branch.
- feature/ml-survival: Anjlee.
- feature/backend-api: Amulya.
- feature/frontend-ui: Ananya.
- feature/factory-analytics: Ankitha.

## Rules

1. Never work directly on main or develop.
2. Work only on your assigned feature branch.
3. Do not modify another member's module without agreement.
4. Pull the latest changes from develop regularly.
5. Commit small, meaningful changes.
6. Push your feature branch.
7. Create a Pull Request targeting develop.
8. Wait for review and tests before merging.
9. Never commit passwords, API keys, .env files or private credentials.
10. Do not force-push shared branches.

## Commit naming

feat(ml): add failure classifier

feat(backend): add machine API

feat(frontend): add machine dashboard

feat(analytics): implement OEE calculator

fix: correct prediction validation

test: add analytics tests

docs: update API contract
