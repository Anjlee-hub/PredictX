# PredictX Frontend UI

React 19 + TypeScript + Vite + Tailwind CSS dashboard and user interface for the PredictX AI-Powered Predictive Maintenance and Factory Intelligence Platform.

## Features
- **Dashboard & Fleet Overview**: Live health scores, real-time KPI metrics, active alerts, and downtime analysis.
- **Machine Details**: Real-time sensor telemetry (vibration, temperature, pressure, acoustic), RUL curves, and degradation stages.
- **AI Predictions & Survival Analysis**: Remaining Useful Life (RUL) estimation, Kaplan-Meier & Cox Proportional Hazards modeling.
- **Factory Analytics**: Overall Equipment Effectiveness (OEE), MTBF, MTTR, loss breakdowns, and dynamic simulations.
- **Explainable AI (XAI)**: SHAP waterfall and feature importance breakdown for failure drivers.
- **Alerts & Smart Dispatch**: Severity classification, alert acknowledgment, and automated maintenance technician dispatch.
- **Custom Futuristic Theme**: High-contrast black, carbon-gray, and amber-orange cyberpunk command center aesthetics with full dark mode support.

## Getting Started

### Prerequisites
- Node.js >= 18
- npm or pnpm

### Installation
```bash
cd frontend
npm install
```

### Development
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### Build
```bash
npm run build
```

### Linting
```bash
npm run lint
```
