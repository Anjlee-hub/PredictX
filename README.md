
# PredictX

### AI-Powered Predictive Maintenance and Factory Intelligence Platform

PredictX is an intelligent predictive maintenance platform designed to
help manufacturing industries monitor machine health, predict failures,
analyse factory performance and make data-driven maintenance decisions.

## Project Modules

### 1. Frontend
React-based dashboard and user interface.

### 2. Backend
FastAPI backend, database integration and REST APIs.

### 3. AI/ML
Machine failure classification, survival analysis and explainable AI.

### 4. Factory Analytics
OEE, downtime analysis, MTBF, MTTR and maintenance recommendations.
